# bro

Restate the last message in plain human language, with no jargon. When a
message comes out dense or jargon-heavy, bro says the same thing the way one
human talks to another: simpler and more concise.

## When it applies

Use whenever the last message needs a plain-language pass. Stop using jargon,
speak coherently, and state it more simply and concisely.

## What it produces

A plain restatement of the last message, not a summary or a new answer. The
original meaning stays intact; only the language gets simpler.

See `SKILL.md` for the full contract.
